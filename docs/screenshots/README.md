# Public screenshots

The screenshots illustrate the real UZEL interface using an isolated loopback
fixture service. Room replies, model labels, chat messages, document metadata and
progress states are synthetic. Image previews use the already public
`image-kit/assets/showcase.png` examples.

- `rooms.jpg`: shared discussion with three participant states and room controls.
- `rooms-create.jpg`: desktop participant preset and the Codex model selector.
- `rooms-mobile.jpg`: room navigation and reading on a narrow screen.
- `chat.jpg`, `chat-mobile.jpg`: local text conversation and copy controls.
- `image.jpg`, `progress.jpg`, `gallery.jpg`, `prompt-series.jpg`: image workflow.
- `les-rag.jpg`: document connection dialog.

The fixture does not launch models or desktop clients, use live credentials,
connect to LES, or read the user's history, gallery or logs. Screenshots are not
benchmark evidence. Live acceptance results and limitations are recorded
separately in [the desktop MCP report](../benchmarks/desktop-mcp-2026-10-14.md).
